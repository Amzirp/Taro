# Числа и карты — Таро и нумерология

Веб-приложение для гаданий на картах Таро и расчёта нумерологии. Полностью
работает в браузере, без бэкенда и установки.

## Возможности

- **Таро Уэйта** — полная колода из 78 карт (Старшие и Младшие Арканы)
- Расклады: одна карта, три карты, «кельтский крест»
- Подробные значения по сферам: общее, любовь, карьера, здоровье, совет
- Ключевые слова к каждой карте
- **Нумерология** — расчёт по дате рождения и имени
- Анимация переворота карт, адаптивная вёрстка

## Запуск

Просто откройте `index.html` в браузере. Всё остальное — статика.

## Структура

```
index.html    разметка, стили и разделы
script.js     колода Таро, расклады, логика нумерологии
images/        78 изображений карт
```

## Стек

Чистый HTML + CSS + JavaScript, без зависимостей и сборки.
